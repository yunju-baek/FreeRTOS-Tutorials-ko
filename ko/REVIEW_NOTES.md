# FreeRTOS 공식 튜토리얼 번역 검수 기록

검수일: 2026-11-01 · 번역: Antigravity · 후속 검수·교정: Codex(모델)

소개 1개와 튜토리얼 21개를 영문 원문과 대조하고 18개 문서의 표현·표기를 교정했다. 현재 상태는 `source-checked`다. 사람의 최종 교열과 예제 빌드·실행·실보드 검증은 수행하지 않았다.

기준 원문은 `FreeRTOS/Lab-Project-FreeRTOS-Tutorials`의 `c89d7164ec6161c57a2ece61df412d6e3e013317`, 한국어 커널북은 `27d03c61cd2a6cf5a6fa6333082218ef706f5b89`다. 인계 지침 v1.0, 커널북 번역 지침 v0.5와 용어집 v0.4를 적용했다.

## 문장 교정

‘유계 없는(unbounded)’은 ‘대기 시간에 상한이 없는(unbounded)’으로, 지나치게 긴 관계절과 피동 표현은 주체·조건을 유지하며 다듬었다. 문체 스킬로 다룬 문장 조각은 108개이며, 이 중 22개는 문서 구분 주석이다. 문체 교정은 34개 조각에 적용했고 도구의 편집 거리 기준 변경률은 10.2%였다. 원문 의미·용어·제목 수정은 별도 교정 기록으로 구분했다.

[내용·용어 교정 기록](../publish/review-2026-11-01/content_changes.json), [본문 전체 변경 내역](../publish/review-2026-11-01/translation-changes.diff)에 근거를 남겼다. 문장 작업표와 검수 전 전체 사본은 제작 원본에 보관했다.

## 보존과 검증 경계

- 최초 번역 24개 파일(본문 22개·manifest·기존 검토 기록)은 제작 원본에 보관했다. 원래 번역자·날짜·검사 선언은 manifest의 `initial_translation_checks`에 남겼다. 공개본에는 검수된 문서와 필요한 검수 근거를 수록한다.
- 본 검수는 Codex 모델이 수행했다. 사람의 전수 교열·예제 코드 완성·빌드·실행·실보드·PDF 검증은 하지 않았다. 검수 이후 사용자의 요청으로 비공식 한국어판을 공개했다.
- 외부 링크는 로컬에 보존된 지정 commit의 Git 객체와 경로로 확인했다. GitHub의 모든 URL에 대한 HTTP 응답 검사는 하지 않았다.
- 이전 원문 보존 clone의 kernel submodule 부재는 당시 상태다. 공개본은 공식 원본을 새로 clone하고 기준 kernel과 하위 port submodule을 확보했다. Git 기준선과 원본 코드를 보존하며, submodule 확보는 빌드·실행 검증을 뜻하지 않는다.
- 발견한 번역·표기 오류는 교정했다. 원문 자체의 불일치는 위 표와 본문 옮긴이 주에 남겼다. `release-ready`로 올리지 않는다.

## 공개본 구성

공식 원본 README는 `README.upstream.md`, 한국어 문서는 `ko/`에 보존한다. 루트 README는 한국어판 안내로 교체했다. 원문 코드·설정·LICENSE·영문 튜토리얼은 그대로다. 커널북 상호 참조는 루트 README와 한국어 목차에 추가했다. 후속 변경은 이 공개 저장소를 기준으로 관리한다.
